## What ships with it

<CardGrid>
  <Card title="Three panels" icon="laptop">
    `/app` for people who use it, `/admin` for people who administer it and `/infra` for people
    who operate it — genuinely separate, each with its own set of permissions.
  </Card>

  <Card title="Multi-tenancy is opt-in" icon="seti:folder">
    It ships off. `php artisan kit:tenancy` turns it on — and it is an install-time decision,
    because the permission tables only grow the context column if it exists before `migrate`.
  </Card>

  <Card title="Permissions ready" icon="seti:lock">
    Filament Shield seeded with roles, a per-panel matrix and a screen to edit all of it.
  </Card>

  <Card title="Configuration on screen" icon="seti:config">
    Identity, mail, tables, registration, login and the kit keys live in
    `/admin/configuracoes-da-aplicacao`. No `.env`, no deploy.
  </Card>
</CardGrid>
