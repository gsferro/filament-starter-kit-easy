# Starter Kit Easy

Kit inicial **Laravel 13 + Filament 5**: três painéis separados, convites, login social,
proteção anti-robô e multi-tenancy opcional.

[![Tela de login](https://raw.githubusercontent.com/gsferro/filament-starter-kit-easy/main/art/thumbs/login.png)](https://raw.githubusercontent.com/gsferro/filament-starter-kit-easy/main/art/login.png)

```bash
composer create-project gsferro/starter-kit-easy meu-projeto
cd meu-projeto && php artisan kit:install
```
